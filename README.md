# Opera by Nagrik

Immersive digital storytelling for an ultra-luxury residential landmark in Majiwada, Thane.

**The Landmark That Gives Back** — Time · Energy · Value

## Stack

- Next.js 16 (App Router) · TypeScript · Tailwind CSS 4
- GSAP + ScrollTrigger · Lenis smooth scroll
- Progressive Web App shell (offline)

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

## Presentation mode

Press `P` to hide chrome for cinematic walkthroughs. `Esc` exits.

## Analytics

Set `NEXT_PUBLIC_GA_ID` to enable Google Analytics. Events also push to `window.dataLayer`.

## Design system

- **Type:** Cormorant Garamond (display) + Outfit (body)
- **Palette:** Deep emerald · Forest · Warm gold · Champagne · Ivory · Stone · Bronze · Charcoal
- **Motion:** expo-out / power easing · no bounce · `prefers-reduced-motion` respected
